GAMESTART - 서버 PC 게임 폴더

사용법
1. 이 폴더 아래에 게임마다 별도 폴더를 만드세요.
   GAMESTART/
   ├── OpenTTD/
   │   ├── openttd.exe 또는 DOS/게임 파일
   │   └── 필요한 데이터 파일...
   ├── StarCraft/
   │   ├── StarCraft.exe
   │   └── 나머지 게임 파일...
   └── NFS_HotPursuit2/
       ├── 실행 파일(.exe)
       └── 나머지 게임 파일...

2. GitHub에 올린 뒤 Actions의 'GAMESTART 목록 갱신' 작업이 완료될 때까지 기다리세요.
3. 사이트의 PC게임 실행기 → 게임불러오기 → 서버 GAMESTART에서 게임 선택을 누르세요.
4. 게임을 선택하면 필요한 파일을 브라우저로 내려받고 기존 PC 에뮬레이터로 실행합니다.

중요
- 게임 폴더의 모든 파일이 브라우저로 다운로드됩니다. 용량이 큰 게임은 로딩 시간이 길고 메모리를 많이 사용할 수 있습니다.
- Windows 게임은 기존 v86 가상 PC 이미지(os/win98 등)가 필요하며, 32비트 실행 파일만 지원합니다. 64비트 Windows 실행 파일은 실행할 수 없습니다.
- DOS 게임은 기존 js-dos 엔진으로 실행합니다.
- OpenTTD처럼 브라우저용 WebAssembly 빌드가 별도로 필요한 게임은 현재 이 자동 PC 실행 경로에서 곧바로 실행되는 것은 아닙니다. 해당 게임 전용 웹 빌드/엔진 연결이 필요합니다.
- 서버에는 본인이 정당하게 사용할 권리가 있는 게임 파일만 올리세요.
- GitHub Pages는 정적 호스팅이므로 폴더 내용을 자동 열람할 수 없습니다. 이 때문에 Actions가 list.json을 생성합니다.
