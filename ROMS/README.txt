[ROMS 폴더 사용법]
기종별 폴더에 게임 파일을 올리면 사이트 목록에 자동으로 나타납니다. (1개 파일 100MB 이하)
 ROMS/GBA   : .gba .zip
 ROMS/NDS   : .nds .zip
 ROMS/PSX   : .bin .cue .iso .chd .pbp .zip
 ROMS/NES   : .nes .zip
 ROMS/MAME  : .zip (바이오스는 기존처럼 MAME/_bios/neogeo.zip, 기존 MAME/ 폴더의 게임도 같이 나옵니다)
 ROMS/SMS   : .sms .zip
 ROMS/PCE   : .pce .zip
 ROMS/DOS   : .zip .jsdos
이름을 한글로 보이게 하려면 폴더 안에 games.json 을 만드세요: {"games":[{"file":"mario.nes","title":"슈퍼마리오"}]}
