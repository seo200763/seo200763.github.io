[3DO 롬 폴더]
이 폴더에 게임 롬 파일을 올리면, 사이트의 "3DO" 화면 게임 목록에 자동으로 나타납니다.
목록에서 게임을 누르면 서버에서 바로 받아 실행돼요.

목록에 나타나는 파일 형식: .iso .chd
※ CD 게임은 .cue+.bin 을 zip 한 개로 묶거나, .chd / .iso 로 만들어서 올리세요. (.cue, .bin 단독 파일은 목록에 나오지 않습니다)
※ 바이오스: BIOS 폴더에 panafz10.bin 를 올려 두세요. (자세한 내용: BIOS/README.txt)

- 파일 하나는 GitHub 100MB 이하여야 합니다. (웹 화면에서 올릴 때는 25MB 이하)
- 이 README.txt 같은 텍스트 파일은 목록에 나오지 않습니다.
- 게임 이름을 한글로 보이게 하려면 ROMS/titles.json 에 적으세요. (ROMS/README.txt 참고)
